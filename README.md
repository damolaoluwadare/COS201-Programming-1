The aim of this exercise is to build a foundation in Java programming by learning how to:

1. Create and organise a Java class.
2. Write statements inside the `main()` method.
3. Display text and information using `System.out.println()`.
4. Compile and execute Java programs.

Open the project folder in your terminal.

Compile the program:

```bash
javac week02/Helloworld.java
```

Run the application:

```bash
java week02.Helloworld
```
